# PILOT Studio 2.4.1 구현·검증 보고서

- 대응 설계: v0.12 / 실행 빌드: `pilot-2.4.1-20261016T014154Z`.
- 적용: 영상용 GPU 렌더링·인코딩과 프레임 캡처 개선. 분해 역산·형상·매칭·지지 알고리즘은 변경하지 않았다.

## 확인한 원인

2.4.0의 영상 브라우저는 headless shell의 SwiftShader 소프트웨어 WebGL을 사용했고, MP4는 CPU libx264로 고정했다. 매 프레임의 장면·문자 갱신과 화면 캡처에도 중복 대기가 있었다. GPU 인코더만 바꾸면 전체 생성 시간이 크게 줄지 않을 수 있어 3D·캡처·인코딩을 함께 개선했다.

## 적용 내용

- 정식 Chromium의 GPU headless 경로 우선 사용, 실제 WebGL 렌더러 기록. 브라우저 시작 실패 시 호환 경로 사용.
- NVIDIA NVENC → Intel Quick Sync → AMD AMF 실제 초기화 시험 후 자동 선택, 미지원 시 CPU.
- GPU 인코더 도중 실패는 동일 불변 입력으로 CPU 재생성 1회. 취소·화면 오류·잘못된 프레임 시간은 성공으로 처리하지 않음.
- 영상은 장면 변경 시 그리며 중복 프레임 대기와 PNG 압축 비용을 줄임. 시간 적용 응답·문자 배치·완료 페인트를 확인한 뒤 무손실 PNG 캡처.
- H.264/yuv420p 출력과 전체 디코딩·정확한 프레임 수 확인 유지. 목록에 인코더와 생성 시간 표시.

## 성능 비교

합성 3부품, 영상 길이 6초, 1280×720, 24fps, 144프레임, 같은 모델·토크·주의사항·템플릿·카메라를 사용했다. 같은 렌더 정의를 기존 2.4.0 프런트엔드/소프트웨어 렌더·CPU 인코더와 개선 경로에 제공했다. 브라우저 실행 파일은 준비된 상태였고 GPU 인코더 확인·브라우저 준비·전체 디코딩 시간은 측정에 포함했다.

- 기존: **32.81초**.
- 개선: **15.16초**.
- 약 **2.16배**, 생성 시간 약 **53.8% 감소**.
- 실제 3D 장치: Intel Arc 140T / Direct3D11. 실제 인코더: RTX 5060 Laptop GPU의 NVIDIA NVENC. 하이브리드 PC이므로 두 단계의 GPU가 다르다.

이는 GPU 사용과 프레임 처리 개선을 합친 단일 실행 비교다. 당시 별도 STEP 매칭 작업도 실행 중이었고 다른 프로세스 부하를 통제한 전용 벤치마크 환경은 아니다. 최초 실행 파일 준비는 추가 시간이 들며 모델·드라이버·해상도에 따라 효과가 달라진다. 회사 정션박스 전체 영상에 같은 배수를 보증하지 않는다.

## 내용·호환·패키지 검증

- 기존·신규 시작/중간/마지막 PNG 프레임의 평균 RGB 차이는 약 0.22–0.24/255. 하드웨어와 소프트웨어 렌더러의 작은 색상 차이를 포함하며, 토크·주의사항·카메라·최종 위치를 확인했다.
- NVENC MP4의 중간 프레임을 실제 디코딩해 PNG와 비교한 평균 RGB 차이는 0.891/255. H.264는 손실 압축이므로 바이트 동일성을 주장하지 않는다.
- GPU 인코더 오류를 주입한 소스 통합 시험에서 CPU로 재생성하고 144프레임 전체 디코딩 PASS.
- 최종 동결 실행 파일에서 실제 GPU 3D·NVIDIA NVENC·144프레임 전체 디코딩 PASS.
- 최종 패키지 신규 STEP 등록 → 순서 생성 → 검증 → 확정 → MP4 → 편집·재검증 및 화면 시험 PASS. JavaScript 오류 0.
- Python 회귀 **205개 PASS**, 101.401초. 신규 인코더 선택·미지원·취소·CPU 호환 시험 포함. TypeScript/프런트엔드 빌드 PASS.
- 네이티브 **2.4.0 → 2.4.1 업데이트**, 데이터·백업 보존, 실패 시 기존 버전 유지 시험 PASS.
- 선택한 소스 104개 SHA가 빌드 전후 동일. 형상·매칭·순서·지지 핵심 8개 모듈은 이전 버전과 동일하다.

## 현재 PC와 남은 범위

현재 PC에서는 사용자의 STEP 등록·매칭 작업이 실행 중이라 파일 사용 잠금으로 설치가 중단됐다(exit 5). 작업을 강제 종료하거나 기존 실행본을 덮어쓰지 않았다. 현재 작업을 마친 뒤 앱을 닫고 새 Setup을 설치하면 된다. 이 PC의 현재 활성 빌드는 `pilot-2.4.0-20261016T000015Z`이며, 동결 패키지 자체의 GPU·UI·업데이트 시험은 별도 격리 환경에서 통과했다.

이번 릴리스는 영상 처리 개선이다. 2.4.0에서 보고한 회사 정션박스의 실링 지지 연결·매칭 6건 미판정과 전체 순서 미완료는 유지된다. 회사 전체 조립성과 별도 PC·현장 인수를 이번 합성 영상 시험으로 완료 처리하지 않는다. 다른 GPU에서의 동작은 실제 초기화 시험과 CPU 호환 경로로 처리하며, 이 PC에서 AMD 성공 경로를 검증한 것은 아니다.
