# PILOT Studio · 팀원 설치·사용 안내

배포 버전: **1.0.0** · 설치본 검증일: **2026-10-12** · 안내 갱신일: **2026-10-13**

## 1. 다운로드

**[PILOT-Studio-Setup-1.0.0.exe 다운로드](https://github.com/gyuwon-k/15-thn_project/releases/download/installer-v1.0.0/PILOT-Studio-Setup-1.0.0.exe)**

다운로드가 되지 않으면 [배포 페이지](https://github.com/gyuwon-k/15-thn_project/releases/tag/installer-v1.0.0)의 **Assets**에서 같은 파일을 선택합니다. 비공개 저장소라면 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다.

**Code → Download ZIP**과 Releases의 **Source code**는 개발 소스입니다. 실행만 하려면 EXE 설치파일을 받으세요. 별도의 dist 폴더 다운로드는 필요하지 않습니다.

## 2. 설치하고 실행하기

1. Windows 10/11 **64비트(x64)** PC에서 설치파일을 다운로드합니다. 약 **1.2GB**입니다.
2. 포함된 프로그램 구성 요소가 약 **3.7GB**를 사용합니다. CAD·프로젝트·영상용 공간도 추가로 확보합니다.
3. **PILOT-Studio-Setup-1.0.0.exe**를 실행하고 설치 안내를 따릅니다. 포함된 구성 요소와 WebView2를 준비합니다.
4. 바탕화면 바로가기가 필요하면 설치 과정에서 해당 옵션을 선택합니다.
5. 설치 완료 후 시작 메뉴의 **PILOT Studio** 또는 설치한 바로가기로 실행합니다.

Python·Node.js·CATIA 개발 환경을 따로 설치하거나 CMD·PowerShell을 실행할 필요는 없습니다. 설치·보안 경고가 발생하면 화면과 메시지를 담당자에게 전달해 확인합니다.

예제 프로젝트가 자동으로 나타나지 않아도 정상입니다. 사용자의 STEP을 등록해 시작합니다.

## 3. 첫 프로젝트와 ASAP 실행

1. **새 프로젝트**에서 제품 정보를 입력합니다.
2. **모델·부품 대응**에서 **완제품만** 또는 **완제품＋하위 부품**을 선택합니다.
3. 완제품 `.stp` 또는 `.step`을 등록합니다. 하위 부품 방식은 기준 부품 STEP도 추가합니다.
4. 3D 형상과 매칭 후보를 검토해 실제 투입할 조립단위를 정합니다. 반복 볼트·와셔는 위치별 배치 ID로 구분합니다.
5. 누락·중복을 확인하고 조립단위를 확정합니다.
6. **OBJ 변환·자동 전처리**를 실행합니다. 차단·경고는 해당 단위의 3D와 상세 진단에서 확인합니다.
7. **ASAP 실행** 후 전처리·전체 순서·실제 경로의 상태를 각각 확인합니다.
8. 성공한 결과를 공정 초안으로 가져와 3D로 재생합니다. 공정·공구·토크·필수 관계를 검토하고 수정했다면 다시 검증합니다.
9. 최신 검증 후 확정한 계획으로 영상·Web ZIP을 출력합니다.

전처리 완료만으로 전체 순서가 생성된 것은 아닙니다. 경로가 없거나 낡은 상태라면 실제 이동이 확보된 것으로 간주하지 않습니다.

## 4. 저장 위치와 프로젝트 전달

각 사용자의 자료는 **%LOCALAPPDATA%\PILOT Studio\data**에 저장됩니다. Windows 탐색기 주소창에 이 경로를 입력하면 됩니다. 팀원 간 자동 공유는 하지 않습니다.

프로젝트 전달·보관은 프로그램의 **저장소·환경 → 백업**으로 ZIP을 만듭니다. 전달받은 사용자는 복원 기능으로 새 저장소를 만들고 프로그램 안내에 따라 확인합니다. 다른 PC에서의 복원은 별도 확인이 필요합니다. 실행 중인 DB 폴더를 직접 복사하지 않습니다. 업데이트 전에는 백업하세요.

## 5. 실행·설치·계산 오류 보고

담당자에게 다음 내용을 전달합니다.

- 설치파일/앱 버전과 Windows 버전
- 입력 방식, CAD 파일명과 조립단위 수
- 실패 단계: 설치 / 앱 시작 / STEP 읽기 / OBJ 변환 / 전처리 / 순서 탐색 / 경로 / 출력
- 오류 코드·메시지와 화면 캡처
- 해당 작업 로그. 공유가 허용된 자료에 한해 CAD 또는 백업을 전달합니다.

로그는 사용자 데이터 폴더의 **logs**와 해당 작업·실행 폴더에 있습니다. ASAP 작업 로그는 **data/asap/jobs/<작업 ID>/worker.log**, 실행 결과는 **data/asap/sessions/<세션 ID>/runs/<실행 ID>**에서 확인할 수 있습니다. 관련 작업의 자료만 전달하세요.

시간 초과·계산 실패는 미완료 상태입니다. 임의로 부품을 빼거나 DB·캐시를 삭제해 성공으로 처리하지 않습니다.

## 6. 현재 배포본의 확인 범위

- 검증 PC에서 설치, 독립 창 실행, 앱 전용 DB 연결을 확인했습니다.
- 검증용 STEP에서 실제 ASAP 순서·경로 생성과 영상·백업을 확인했습니다.
- 실제 HVJB는 전체 전처리를 확인했지만 **전체 조립순서 성공은 아직 확보하지 않았습니다**.
- 실제 PRA와 다른 PC의 인수는 별도 시험이 필요합니다.
- 이 파일은 **2026-10-12 검증 설치본**이며 이후 진행 중인 HVJB 개선이 모두 들어간 버전은 아닙니다. 업데이트는 [Releases](https://github.com/gyuwon-k/15-thn_project/releases)에서 확인하세요.

## 7. 폴더 형태의 배포본을 받은 경우

설치파일 대신 **PILOT-Studio 폴더 전체**를 전달받았다면 폴더 안의 **PILOT-Studio.exe**를 실행합니다. **_internal**을 포함한 폴더 구조를 유지해야 합니다. EXE만 옮기면 필요한 구성 요소를 찾지 못합니다. 새 PC에는 설치파일을 사용하는 방식을 권장합니다.
