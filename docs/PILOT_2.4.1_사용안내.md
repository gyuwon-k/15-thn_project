# PILOT Studio 2.4.1 사용 안내

대응 설계서: PILOT 구현설계 v0.12. Windows 설치형 프로그램이며 완제품에서 분해 경로를 찾고 그 역순으로 조립순서를 생성한다.

## 설치와 업데이트

`PILOT-Studio-2.4.1-Setup.exe`를 실행하고 기존 PILOT Studio 바로가기로 연다. 설정에서 화면과 서비스가 모두 2.4.1이고 실행 빌드가 일치하는지 확인한다. 기존 프로젝트·원본·확정본·영상은 사용자 저장소에 보존한다. 정상적으로 등록된 기존 모델의 STEP을 이번 변경만으로 다시 등록할 필요는 없다. 원본이 그대로인 기존 프로젝트는 형상 검사 실패가 남아 있어도 순서 생성 또는 재검증을 누르면 필요한 형상만 자동으로 다시 검사한다. 기존 단위·매칭·공정 규칙·작업 정보는 유지한다. 분석 형상이나 검사 기준이 바뀐 기존 초안의 PASS는 새 검사로 확인한다.

## 순서 생성과 확정

1. 프로젝트를 열고 모델 대응과 조립최소단위를 확인한다. 함께 잡고 설치해야 하는 부품은 하나의 단위로 묶는다.
2. 시작 고정품과 제품의 필수 선후·체결 규칙을 확인한다. 정션박스는 메인바디 → 플레이트 → 릴레이 순서와 각 부품의 고정 완료 조건을 적용한다. 릴레이 고정 볼트는 실제 높이가 높은 위치부터 체결하고 높이가 같으면 순서를 강제하지 않는다.
3. 필요한 경우 허용·선호 진입 방향을 지정한다. 방향은 제품 좌표계 기준이다. +Z는 제품 −Z 쪽에서 +Z로, −Z는 제품 +Z 쪽에서 −Z로 이동한다. 화면에서 보이는 위아래와 다를 수 있다.
4. 순서 생성을 실행한다. 필요한 형상 자동검사를 먼저 수행하고 현재 남은 모든 부품에 대해 분해 경로를 검사한다. 커버가 버스바의 경로를 막으면 커버를 먼저 제거해야 하며, 지지 부품을 먼저 빼서 다른 부품이 공중에 남는 후보도 채택하지 않는다. 어떤 부품에 의존하는 핀·부품이 남아 있으면 그 부품을 고정하는 볼트를 먼저 풀지 않는다.
5. 전체 분해 경로를 찾으면 역순으로 조립 계획을 만들고 각 단계의 간섭·선후 규칙·지지 연결을 다시 검증한다.
6. 최신 전체 검증을 통과하면 순서를 확정한다. 토크·주의사항·작업정보 검토 체크·기록자 이름은 선택 사항이며 비어 있어도 확정할 수 있다. 확정 성공 후 현재 프로젝트의 확정 상태와 버튼이 갱신된다.
7. 회사 영상 템플릿을 선택하고 필요한 단계에 토크·주의사항을 입력하여 MP4를 생성한다. 입력하지 않은 정보는 미입력으로 표시하며 자동으로 ‘해당 없음’이나 ‘검토 완료’가 되지 않는다.

순서·방향·거리·고정품·규칙을 바꾸면 다시 검증한다. 작업 정보만 바꾸는 경우에는 같은 경로의 검증을 재사용할 수 있다.

## 형상 자동검사 결과

모델 결과 패널에서 보정 수와 보류 수를 확인한다. 공정·규칙 화면의 ‘형상 자동 검사 결과’에서 부품별 상태를 보고, 보류 원인은 진단 결과에서 확인한다. 검사 결과는 읽기 전용이며 별도 승인자 이름·근거·필수 확인 체크를 입력하지 않는다. 원본 경고가 있어도 자동 검사로 분석에 사용할 수 있는 형상이 확보되면 순서 생성을 계속한다.

이번 보정은 STEP을 읽어 만든 원본 CAD 형상의 곡선·표면·경계·정점·배치·구성원을 유지하면서, 측정된 오차에 맞게 필요한 국소 허용오차 정보만 제한적으로 정정한다. 저장 후 다시 읽어 일반 검사와 정밀 검사를 모두 통과한 결과만 사용한다. 형상을 이동하거나 줄여서 맞추거나 경고를 일괄 무시하는 기능은 아니다. 원본·최초 실패·보정 내역은 보존한다.

형상 누락·열린 경계, 보존 불일치, 보정 범위 초과, 측정·정밀 검사 실패는 보류한다. 이런 경우 보류 원인을 먼저 해결해야 한다. 자동 보정 성공은 입력 CAD 정밀도에서 간섭 분석을 진행할 수 있다는 뜻이며 실제 제조 간극이나 정밀 끼워맞춤을 보증하지 않는다. 좁은 틈의 영향이 중요한 경우 표현 불확실성을 반영하는 여유 검사가 필요하다.

저장된 원본과 현재 원본 파일의 SHA가 다르면 자동 재평가를 중단하고 STEP 재등록을 안내한다. 바뀐 원본에는 기존 표시·매칭 정보를 그대로 사용할 수 없기 때문이다. 파생 분석 파일만 손상된 경우에는 보존된 원본으로 다시 생성할 수 있다. 원본 SHA를 저장하지 않은 구버전 자료는 최초 평가에서 기록한다.

자동 재평가로 분석 형상이 바뀌면 기존 순서·작업 정보는 그대로 두고 이전 경로 검사 결과만 무효화하여 다시 검증한다. 새 순서를 찾지 못해도 완료된 형상 재평가 결과는 유지한다. 취소하거나 작업 자체가 실패하면 미완료 결과를 현재 모델에 적용하지 않는다.

## 계산 시간

생성 기본 제한은 30분, 완성 후보의 전체 조립 재검증 기본 제한은 별도로 30분이다. 따라서 두 단계가 모두 오래 걸리면 전체 작업은 약 60분과 결과 저장 시간까지 걸릴 수 있다. 후보 하나와 네이티브 연산의 기본 제한은 각각 120초다. 시작 시 필요한 형상 자동 재평가도 해당 단계의 30분 안에 포함한다. 재평가 후 별도의 30분을 다시 시작하지 않는다.

구형 프로젝트에 남아 있던 300초·4초·20초 기본값도 새 기본값으로 이행한다. 그 밖의 사용자 지정값은 보존한다. 새 버전에서 의도적으로 시간을 변경하면 그 값을 유지한다. 진행 중에는 취소할 수 있다. 시간이 끝났다는 결과는 조립 불가능을 뜻하지 않으며 미완료 상태와 차단 원인·시도 기록을 보존한다.

## 정상 완제품 기준과 지지 검사

완제품 STEP의 최종 배치는 정상 조립 상태로 받아들인다. CAD의 최종 겹침만으로 생성을 차단하지 않고, 부품이 움직이며 새로 발생하는 간섭을 검사한다. 해당 조립 단위의 모든 구성원이 최종 위치에서 차지한 실제 형상 영역만 기준으로 사용하므로 그 밖의 하우징 벽이나 커버를 통과하는 이동까지 허용하지 않는다. 화면에서 숨긴 부품도 검사에는 포함된다.

지지는 제품 −Z 방향의 작은 실제 형상 탐침과 고정품까지의 연결로 확인한다. 실제 수평 원통 맞춤에는 제한된 안착 여유를 적용하고, 축·구멍·머리 안착으로 체결 대상이 하나로 확인되면 고정 순서도 연결한다. 멀리 떨어진 볼트를 임의로 배정한 것만으로 지지됨을 인정하지 않는다. 고정품·치구가 전혀 없으면 최저 높이의 수평 작업대 가정을 기록하고, 실제로 놓인 하단 부품부터 지지를 연결한다. 질량·마찰·전도·체결력을 계산하는 물리 시뮬레이션은 아니다. 실제로 지그가 필요한 구조는 지그·고정 조건으로 표현해야 한다.

## 결과를 찾지 못한 경우

최근 탐색 결과에서 남은 단위, 간섭 대상, 지지 연결 단절, 형상 미판정, 시간 종료를 구분해 확인한다. 부분 분해를 전체 조립순서로 채우지 않으며 기존 계획과 작업 정보는 보존한다. 분석 형상이 바뀌어 이전 검증이 무효화된 경우에는 현재 형상으로 다시 검증해야 한다. 형상 문제나 실제 경로 차단을 정보 체크나 순서 확정으로 우회할 수는 없다.

버전별 실제 CAD 시험 결과와 패키지 검증 결과는 별도 검증 보고서를 확인한다. 설계 기능과 개발 시험 결과를 회사 제품 전체 통과나 현장 승인으로 혼용하지 않는다.


### 형상 작업 결과 전달

네이티브 형상 작업자는 매 시도마다 고유 결과 파일에 완성된 결과를 원자적으로 저장한다. Windows 공유 세마포어 전달 오류가 정상 형상 검사를 실패시키지 않도록 형상 보정 결과는 이 방식으로 수신한다. 다른 시도의 결과나 임시 파일을 재사용하지 않는다. 취소·시간 초과·작업자 종료로 결과를 받지 못하면 통과 처리하지 않고 원본과 기존 프로젝트를 보존한다.


## 영상 GPU 가속

영상 출력은 GPU를 자동으로 선택한다. NVIDIA·Intel·AMD 인코더의 실제 작동을 확인하며, 지원되지 않는 PC에서는 CPU 인코딩을 사용한다. 3D 화면 렌더링도 가능한 그래픽 장치를 사용한다. 별도 CUDA 도구나 개발용 SDK 설치는 요구하지 않는다. 노트북에서는 3D와 MP4 인코딩이 다른 GPU에서 처리될 수 있다.

영상 목록에서 사용 인코더와 생성 시간을 확인한다. 최초 출력은 영상 브라우저 실행 파일 준비 때문에 더 오래 걸릴 수 있다. GPU를 사용해도 모델 읽기·프레임 캡처·템플릿 문자 배치·최종 파일 검사는 함께 수행되므로 전체 작업이 모두 GPU로 처리되는 것은 아니다.

같은 확정 모델·카메라·토크·주의사항·해상도·fps를 유지한다. GPU 인코딩이 도중에 실패하면 CPU로 같은 영상을 한 번 다시 생성한다. 취소한 작업과 화면·경로 오류는 완료 처리하지 않는다. 출력 전 현행 버전의 검증이 필요한 경우 조립성 재검증 후 새 확정본을 선택한다.
