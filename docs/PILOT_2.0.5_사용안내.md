# PILOT Studio 2.0.5 사용 안내

## 시작

`PILOT-Studio-2.0.5-Setup.exe`를 설치하고 `PILOT Studio` 바로가기로 실행한다. 저장소·환경에서 실제 앱 버전 **2.0.5**과 실행 빌드를 확인한다. 설치 파일이 들어 있는 폴더의 과거 실행 파일을 직접 실행하는 방식은 사용하지 않는다.

프로그램과 사용자 데이터를 분리해 보관한다. 현재 세대의 업데이트는 기존 프로젝트를 유지한다. 이전 세대 DB는 자동 변환하지 않으며 기존 폴더를 덮어쓰지 않는다.

## 정션박스 검토 결과 열기

제공된 `HVJB_검토용_프로젝트_v2.0.5.zip`은 이번 시험에서 생성한 **검토 초안**의 백업이다. 저장소·환경에서 백업 파일을 선택하고 복원 검증 결과를 확인한 뒤 적용·재시작한다. 기존 데이터가 있으면 먼저 백업한다. 복원은 새 저장소를 만들어 적용하며 프로젝트를 현재 저장소에 병합하는 기능은 아니다.

이 자료는 전체 조립성 통과본이 아니다. 78개 배치가 56개 조립 단위로 구성되며, 고정 하우징을 제외한 55단계 초안과 실제 검사 진단을 확인할 수 있다. 정식 작업 영상으로 확정하려면 미해결 항목을 검토하고 전체 검증을 통과해야 한다.

## 새 프로젝트 작업 순서

1. 프로젝트에서 차종·품목·품번·이름을 등록한다. 품번의 앞자리 0은 유지된다.
2. 모델·조립 순서에서 완제품 STEP을 등록하고 필요한 부품 STEP들을 함께 선택한다.
3. 부품 대응과 모델 검증 결과를 확인한다. 품명 변경, 배치 묶기·해제, 표시 숨김, 고정 조립품 변경을 할 수 있다. 화면에서 숨긴 부품도 간섭 검사에는 남는다.
4. 공정·조립 규칙에서 고정품·선후 관계·진입 방향과 계산 예산을 정한다. 순서 생성을 실행한다.
5. 하단 카드와 3D 화면에서 순서를 확인한다. 카드 드래그나 진입 방향·거리 변경은 재검증으로 연결된다.
6. 단계별 토크 또는 해당 없음, 주의사항 또는 검토 결과 없음, 작업 정보 검토 표시를 저장한다. 전체 조립성 검증이 통과한 현재 계획만 확정할 수 있다.
7. 영상 출력에서 검토한 회사 양식을 선택한다. 자동 시점을 확인하고 필요한 단계는 3D 화면에서 시점을 저장한다. 출력 영상은 토크·주의사항과 저장된 이동 경로를 사용한다.
8. 이력·학습에서 확정본·수정 기록·회사 평가·필드테스트 결과를 축적한다. 학습은 별도 전문가 선호 검토와 설정 기준을 충족한 자료로 진행한다.

## 결과를 읽는 방법

- **모델 제한:** 표시와 매칭은 가능하지만 표현 검사 차이 등 검토할 조건이 남아 있다.
- **간섭 발견:** 계산한 부품 쌍 또는 이동 구간에서 겹침이 확인됐다.
- **미판정:** 시간 예산 또는 기하 연산 한계 때문에 통과 여부를 확인하지 못했다.
- **검토용 순서:** 모든 작업이 배열에 포함됐지만 아직 전체 검증은 통과하지 않았다.
- **검증 통과:** 현재 모델·규칙·순서·지원 이동 범위에 대한 검사 결과다. 공구 접근성, 탄성 변형, 지그 안정성은 별도 현장 검토 대상이다.

STEP 변환 경고는 그 자체로 부품 충돌을 뜻하지 않는다. 반대로 3D가 표시되거나 순서 카드가 생성됐다는 사실만으로 조립성이 검증된 것은 아니다.

정션박스에서 발견된 최종 배치 겹침은 순서 변경만으로 해결되지 않을 수 있다. 설계상 의도된 결합이면 담당자가 해당 두 단위·국소 영역·종단 진입 거리·검토 근거를 지정한다. 실제 형상 오류이면 수정 STEP을 새로 등록한다. 단위 쌍 전체를 검사에서 제외하지 않는다.

## 업데이트·백업·복원

새 설치 파일로 업데이트한 뒤 저장소·환경의 실제 버전을 확인한다. 릴리스 구성 요소가 섞이거나 필수 런타임 검사가 실패하면 새 버전 활성화를 중단하고 이전 자료를 보존한다.

백업에는 등록 원본, 형상·장면, 프로젝트 개정, 확정본, 영상과 학습 자료가 포함된다. 복원 파일은 해시·행 수·확정본 무결성을 검증한 뒤 새 저장소로 적용한다. 작업이 실행 중이면 완료 또는 취소 후 전환한다.

## 현재 적용 범위

단위별 고정 자세의 직선 이동과 여섯 축 방향을 검사한다. 방향 기반 자동 카메라와 수동 저장을 지원한다. 회전 경로, 공구 접근 계산, 탄성 끼워맞춤 해석, 자동 가림 최적화, 별도의 이동 없는 체결·검사 단계 생성은 현재 기능 범위에 포함하지 않는다.

회사 승인 양식·토크·주의사항, 끼워맞춤 허용 범위, ML의 현장 성능은 실제 담당자의 검토와 시험 자료로 확정한다. 프로그램이 그 결과를 자동으로 만들어 채우지 않는다.
