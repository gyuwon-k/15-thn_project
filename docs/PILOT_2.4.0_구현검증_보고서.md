- 작성일: 2026-10-16
- 대응 설계: PILOT 구현설계 v0.11
- 상태: 최종 설치 빌드 `pilot-2.4.0-20261016T000015Z` 검증 완료. 회사 제품 전체 순서는 미완료이며 원인은 §5에 구분한다.

## 1. 문제 원인과 수정 범위

기존 판정은 모서리의 측정 잔차와 보정 후 허용오차 전체 값에도 0.01 mm 상한을 적용했다. 이 때문에 원본에 이미 선언된 모서리 허용오차가 큰 경우에는 필요한 추가 증가량이 작아도 분석에서 제외될 수 있었다. 또한 잔차 측정에 사용한 어댑터와 OCCT 정밀 검사의 어댑터가 달라 최대값에 작은 수치 차이가 발생했고, 보정 후보가 마지막 정밀 검사를 통과하지 못하는 사례가 있었다.

2.4.0은 원본 모서리의 기존 허용오차를 기준으로 추가 증가량만 제한하고, 잔차 측정 어댑터를 OCCT 정밀 검사와 일치시켰다. 정책은 `measured-unchanged-cad-2.4.0`, 잔차 측정은 `native-reference-extrema-2.4.0`, 분석 캐시는 `analysis-geometry-2.4.0`으로 구분한다.

- 엄격 보정의 추가 증가 상한: 0.0001 mm.
- 조립 분석용 추가 증가 예산: `max(0.0001, min(0.05, 원본 형상 bbox 대각선(mm) × 0.001))` mm.
- 잔차 전 구간 측정, 독립 표본 대조, 필요한 경우 전체 구간 분할 재시도를 유지한다.
- 측정값에 필요한 수치 여유도 증가 예산에 포함한다. 다른 부품이나 다른 모서리의 큰 허용오차를 가져와 적용하지 않는다.
- 3D 곡선·면, 2D 면 위 곡선, 트림, 정점, 배치·토폴로지·솔리드를 보존한다. 후보와 저장 후 다시 읽은 형상 모두 일반·정밀 검사를 통과해야 한다.

수정 대상은 표현 메타데이터와 그 측정 방식이다. 형상을 이동·축소·삭제하여 맞추거나 검사 실패를 무시하는 방식은 적용하지 않았다. 보존 비교의 기준은 STEP 전송 후 생성된 원본 BREP이다. 입력 STEP의 전송 경고와 최초 검사 결과는 별도로 남긴다.

### 2.4 기하 보존과 검사 결과의 의미

이로써 해당 입력을 명목 CAD 간섭 분석에 사용할 수 있는 근거를 확보했다. 실제 제조 간극이나 정밀 끼워맞춤을 인증한 것은 아니다. 보정량이 작더라도 입력 허용오차보다 좁은 틈에 영향이 전혀 없다고 일반화하지 않는다. 필요 시 `uncertainty_clearance` 모드에서 표현 불확실성을 반영하여 판정한다.

## 3. 보정이 간섭 검출을 약화시키는지에 대한 시험

- 형상·재료 적분값 보존 확인.
- 받침 위 열린 진입 경로는 명목 CAD 검사에서 PASS.

- 메인바디를 뚫고 진입하는 경로는 COLLISION.
- 명목 CAD 경로 통과가 표현 불확실성을 고려한 여유 검사 통과로 바뀌지 않으며, 해당 접촉 조건은 UNKNOWN.

**6개 시험 모두 통과**, 로그 실행 시간 6.077초. 증적: `path-regressions.log`. 각 시험 안에서 두 표현 조건을 구분하여 확인했다. 이 합성 반례 시험은 회사 제품 전체 경로 시험과 별개다.

## 4. 기존 프로젝트 자동 적용

소스에 반영한 동작은 다음과 같다. 설치 패키지에서 동일하게 실행되는지는 §5에서 별도로 확인한다.

1. 기존 프로젝트에서 순서 생성 또는 재검증을 실행하면 미해결 형상 배치만 최신 정책으로 재평가한다. STEP을 다시 등록하거나 단위를 새로 만들 필요가 없다.
2. 이미 정밀 통과한 배치는 반복 처리하지 않는다. 최신 정책으로 평가한 실패 행은 원본·분석 파일 해시가 같을 때 결과를 재사용한다. 저장된 원본 SHA와 현재 원본 파일이 다르면 재평가를 금지하고 STEP 재등록을 안내한다. 바뀐 원본에 기존 bbox·장면·매칭을 유지할 수 없기 때문이다. 원본은 같고 파생 분석 파일만 손상됐다면 불변 원본에서 재생성할 수 있다. 원본 SHA가 없는 구버전 자료는 최초 평가에서 기록한다.
3. 원본 BREP에서 파생 분석 후보를 만들고 장면·배치·단위·매칭·규칙·작업 정보를 보존한다. 재평가 시간을 기존 생성/검증 단계 예산에서 차감한다.
4. 새 분석 결과가 적용되면 과거 경로·검증 PASS를 무효화하고 현재 형상으로 다시 검증한다. 전체 순서를 찾지 못해도 완료된 분석 결과는 보존하며 기존 계획·작업 정보는 유지한다.
5. 처리 중 원본 변경은 `ANALYSIS_SOURCE_HASH_MISMATCH`로 게시를 차단한다. 취소·작업 실패·자산 등록 실패로 불완전한 새 모델을 현재 프로젝트에 연결하지 않는다.
6. 사용자에게 보정 수·보류 수를 보여준다. 별도 표현 승인자·검토 근거·필수 체크로 형상 실패를 우회하거나 정상 보정을 추가 승인하게 만들지 않는다.

릴리스는 `analysis_geometry_version=2.4.0`을 별도로 기록한다. STEP 전처리·매칭·기본 형상 백엔드의 호환 버전은 2.1.0을 유지한다. 형상 정책 갱신만으로 기존 단위 ID와 공정 정보를 폐기하지 않는다.

### 5.1 회사 제품 전체 탐색의 남은 문제

동일 기하 정책의 소스 시험에서 56단위·78형상을 대상으로 약 25.6분 실행했다. 원본·배치·단위 정의는 보존했고 형상 보류는 2개에서 0개가 됐다. 최종 결과는 **UNKNOWN, 완성 순서 0단계**다. 최종 패키지 전체 순서 성공으로 계산하지 않는다.

- 55개 분해 후보 모두 `SUPPORT_GEOMETRY_UNRESOLVED`: SEL-KD000 실링의 고정품까지 지지 연결을 확정하지 못했다.
- 지지 관계 68건은 확인했고 5건은 네이티브 계산 시간 초과로 미판정이다. PLT–HVSC, LV CONT–HVSC, HVSC–실링 관계가 포함된다.
- 기존 매칭 검토 6건도 남아 있다. 별도 재검사에서 해당 19개 구성 형상 중 13개는 동일성 대조 통과, 6개는 시간 초과 또는 Boolean 연산 미완료·유효하지 않은 결과였다. 오대응으로 판명된 것은 아니다.
- 재검사한 5개 부품 STEP의 템플릿 18개는 모두 정밀 검사 통과. 원본 입력 161개 파일의 SHA는 불변이다. 재검사 중 부모 작업에서 결과 전달·원본 해시 보호 코드가 바뀌어 완전한 소스 동결 시험은 아니며, 기하 보정·잔차·매칭 핵심 3개 모듈은 동일했다. 이 보조 시험을 최종 패키지 매칭 인수로 계산하지 않는다.

따라서 잔여 OCCT 정밀 검사 실패는 해결됐지만 회사 제품 전체 순서 생성까지 해결됐다고 할 수 없다. 지지 관계 추론과 복잡 형상 비교의 연산 미완료가 후속 개선 대상이다. BREP 유효성 통과만으로 모든 Boolean·지지·경로 계산의 성공을 보증하지 않는다.
